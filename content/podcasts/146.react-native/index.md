David Leuliette fait du React Native depuis 2016. Il a fondé weshipit.today, une agence spécialisée dans les apps React Native, il forme des développeurs au sein du React Native Bootcamp de Human Coders et il anime le Cross Platform Show, un podcast francophone dédié à React Native. Il est aussi Microsoft MVP.
